# For Aira — My Favourite Chapter

Upload these files to GitHub Pages. Put your 50 original JPEGs in `assets/photos/` and preserve their exact filenames.

- `index.html`
- `style.css`
- `script.js`
- `assets/photos/`

The project includes 160 pages, Indonesian/English language switching, 50 reasons, 12 letter-themed pages, nine interactive game pages, envelopes, guestbook, scrapbook photo references and the final LESBICUUUU reveal.

The language switch changes the current page language; the book does not show both languages together. Guestbook text is saved only in the visitor's current browser.
