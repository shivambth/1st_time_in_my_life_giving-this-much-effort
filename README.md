# Aira's 4-Month Anniversary Digital Love Book ❤️

Static vanilla HTML/CSS/JavaScript project for Shivam and Aira.

## Run / publish
Open `index.html` in a modern browser (or use VS Code Live Server). For GitHub Pages, upload the contents of this folder to a repository, then select **Settings → Pages → Deploy from branch → main / root**.

## Your 50 real JPEG photos are not attached yet
This ZIP contains 50 manifest slots, **not the original photos**. The exact filename list was not supplied in this chat. The placeholders currently reference `assets/photos/photo-file-01.jpeg` through `photo-file-50.jpeg`. Put your originals in `assets/photos/`, then edit `photoManifest` near the top of `script.js` so each `src` is the exact original filename. No original image is renamed or modified. Missing files leave a photo placeholder.

## Included
- Hardcover cover and paper-book reader; exactly 200 rendered pages and matching counter.
- Previous/next, keyboard arrows, mobile swipe, desktop drag gesture, reading progress in localStorage.
- Indonesian/English toggle; twelve distinct personal letter pages with English versions, fifty unique reasons, ten open-when envelopes.
- Nine different playable mini-game mechanics, restart controls, photo slots/lightbox, guestbook local save.
- Responsive styling and no backend or paid service required.

## Honest notes
The 12 letters are personal drafts based only on the facts supplied, and are shorter than the requested 450–550 words each. The English versions are concise translations/adaptations, not word-for-word full-length translations. The 200 pages are populated with story, letters, reasons, games, envelopes, timeline, guestbook, photo pages and short reflection pages; not every page is a 450-word essay. The sound toggle is a UI toggle only, not a song. Guestbook and reading position are stored locally on the current device and do not sync.
